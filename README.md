# Achados & Perdidos

Sistema web para cadastro, consulta e organização de objetos encontrados.

## Estrutura

- `index.html`: estrutura da página.
- `css/style.css`: estilos e layout responsivo.
- `js/script.js`: funcionalidades e armazenamento local.

## Como executar

Abra o arquivo `index.html` em um navegador.

## Observação sobre os dados

Esta versão utiliza `localStorage` do navegador. Os registros ficam salvos no navegador/dispositivo em que foram cadastrados; não há banco de dados compartilhado entre usuários.
