# Organizador-de-achados-e-perdidos
## Objetivos
Nossa equipe desenvolveu um **sistema de Achados e Perdidos** destinado a universidades, com o objetivo de facilitar o controle e a devolução de objetos encontrados no campus.

Quando um objeto é encontrado, um funcionário cadastra informações como **descrição, categoria, local, data e foto**. O sistema gera um código de identificação e registra onde o objeto está armazenado.

Alunos e funcionários podem acessar a plataforma para **pesquisar objetos perdidos** e solicitar sua devolução. O responsável analisa a solicitação e, após confirmar o proprietário, registra a entrega.

Assim, nosso sistema oferece às universidades uma solução **organizada, segura e prática** para administrar objetos perdidos e encontrados.
